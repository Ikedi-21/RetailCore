# RetailCore: Console Inventory and POS

Command-line inventory and point-of-sale system. Java 17, Maven, Gson, JSON persistence.

**Status:** in development (Day 1 of 10).

## Requirements
- Java 17 or newer
- Maven 3.9 or newer

## Build and test

    mvn -B verify
